# uob-cs-conversion-guide
<img width="1024" height="572" alt="image" src="https://github.com/user-attachments/assets/49960bb8-8426-4727-925c-ea66a29c5a8c" />
A comprehensive, community-driven resource hub for the MSc Computer Science (Conversion) program at the University of Bristol. Includes past exam papers, curated learning materials, study strategies, and local lifestyle tips.

## 🌐 Language / 语言声明

This repository is maintained in both **English** and **Simplified Chinese** to support a diverse community of students.

本仓库采用**中英双语**维护，旨在为不同背景的同学提供支持。

* English version: Default or `.md`
* 中文版本: 以 `.zh.md` 结尾或在文件内标记

## 🛠️ Contribution & Commit Specs / 提交规范

To maintain logical consistency and a clean history, this project follows the [Conventional Commits](https://www.conventionalcommits.org/) specification. Please use the following format for your commits:

为了保持逻辑一致性和清晰的提交历史，本项目遵循**约定式提交**规范。请按以下格式提交：

`type(scope): description`

**Common Types:**
- `feat`: New guide or resources (e.g., `feat(exam): add 2024 Java paper`)
- `fix`: Correcting errors in solutions or links
- `docs`: Documentation only changes
- `style`: Formatting, no content change
